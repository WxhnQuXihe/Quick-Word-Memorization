## 1. 开发约定（不要跑偏）

- 后端：Spring Boot 3.2 + Java 17 + MyBatis-Plus 3.5.x + MySQL 8。
- **业务代码零 SQL**：全部 `LambdaQueryWrapper` / `QueryWrapper`，不写 XML、不写 `@Select`；复杂选词在 Java 内存里算。
- **不写自定义泛型基类**；Mapper 直接 `extends BaseMapper<Xxx>`；Service 用具体类型。
- 用户端：Vue 3 + Vite + TypeScript + Pinia + Vue Router + Vant 4 + Capacitor 6。
- 管理后台：Vue 3 + Vite + TypeScript + Element Plus。
- 用户端主题：A · 纸感编辑（暖白 / 墨黑 / 朱砂）。
- 管理后台主题：A · Mission Control（深石墨 / 酸性青柠）。
- 软件名：**神也背单词**；项目名/库名/目录：`shorthand`。
- 不做：注册、SRS/遗忘曲线、每日目标、TTS 读音、支付、社区。
