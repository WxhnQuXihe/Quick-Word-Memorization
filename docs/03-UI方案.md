## 3. 关键页面

### 3.1 登录页

```
┌──────────────────────────┐
│           拾词            │
│      每天拾起一点词汇       │
│                          │
│  账号  ┌──────────────┐   │
│        └──────────────┘   │
│  密码  ┌──────────────┐ 👁 │
│        └──────────────┘   │
│                          │
│      [   登 录   ]        │
│                          │
│  注册暂未开放 · 忘记密码？  │
└──────────────────────────┘
```

- 账号/密码两个输入框，密码右侧眼睛切换。
- 「注册」点击 toast：**暂未开放注册，请联系管理员**。
- 「忘记密码」点击 toast：**请联系管理员重置密码**。
- 登录中按钮 loading，成功后进主页。

### 3.3 背单词页（核心）

```
┌────────────────────────────┐
│ ‹   四级大纲 4427   第 3 / 443 组│
│     本轮 27 / 443 组  ▓▓▓░░░  │
├────────────────────────────┤
│ 01  abandon          ✓标熟 ☆收藏│
│     /əˈbændən/              │
│     ─────────────────────   │
│     v. 放弃；遗弃；离开…      │
├────────────────────────────┤
│ 02  evaluate         ✓标熟 ☆收藏│
│     /ɪˈvæljueɪt/            │
│     ─────────────────────   │
│     v. 评估；估价            │
├────────────────────────────┤
│ ...（共 10 张卡，纵向滚动）   │
└────────────────────────────┘
│ 隐藏单词 │ 隐藏释义 │ 下一组 │  ← 固定底栏
```

**卡片交互：**

- 点单词区：只隐藏该卡单词（含音标），释义仍显示；再点恢复。
- 点释义区：只隐藏该卡释义，单词仍显示；再点恢复。
- 隐藏时用同高度占位块（虚线 + "点击显示单词/释义"），避免页面跳动。
- 熟词/收藏按钮 `stopPropagation`，不触发隐藏。

**熟词替换：**

- 点「标熟」→ 卡片绿色闪一下 → 内容换成随机新词（淡入/左滑），position 不变。
- 没有可替换词 → 卡片变成"本组已全部标熟"，本组词数减一。
- 收藏只变琥珀星，不换词。

**底栏：**

- 「隐藏单词」：本组所有卡单词一次性隐藏，文案变「显示单词」；再点全部显示。
- 「隐藏释义」：同理。
- 「下一组」：两段式确认——
  1. 第一次点击：变「再点一次进入下一组」，警示色，3 秒倒计时；
  2. 3 秒内再点：请求下一组，成功后滚回顶部，toast「第 4 组」；
  3. 超时：恢复「下一组」。

- 提醒开关先存后端字段，通知能力后续再加。

### 3.5 收藏夹 / 熟词本

- 列表项：单词 + 音标 + 释义首行 + 右侧星标/对勾。
- 点星标/对勾一键移出，计数全局同步。
- 空态：不写"暂无数据"，直接引导去背单词。
- 收藏夹顶部「背收藏夹」；熟词本顶部「背熟词本」（可选）。

### 3.6 管理后台

Element Plus 常规后台，不做花哨设计：

```
┌────────┬──────────────────────────┐
│ 词书管理 │  词书列表                 │
│ 词条管理 │  ┌────────────────────┐  │
│ 导入记录 │  │ 名称 词数 状态 操作  │  │
│ 用户管理 │  └────────────────────┘  │
│ 反馈管理 │                          │
└────────┴──────────────────────────┘
```

- 词书：新建/编辑/上架/导入词条。
- 导入：选词书 → 上传 Excel → 显示成功/失败行 → 下载失败文件。
- 用户：新增、重置密码、禁用。
- 反馈：查看、回复。

## 4. 桌面适配

- `≥1024px`：左侧固定导航（主页 / 我的 / 收藏夹 / 熟词本），右侧内容区最大 720px 居中。
- 背单词页：
  - 方案 A：仍单列 720px，滚动少一点；
  - 方案 B：两列卡片（5 + 5），一屏看完；
  - 方案 C：左侧词卡列表 + 右侧固定"本组信息/操作"。
- 手机端保持单列；平板可两列。
- 管理后台本来就是桌面布局。
