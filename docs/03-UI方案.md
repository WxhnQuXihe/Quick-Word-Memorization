## 1. 三个视觉方向（已选 A）

原型里做了三套**结构不同**的方案，底部有 A/B/C 切换器，也可用键盘 ← → 切换。最终选 **A**，B/C 只留作对比记录。

### A · 纸感编辑（推荐主风格）

- 暖白纸底 `#F5F1E8`，墨黑字 `#1A1713`，朱砂红 `#B4432F` 点缀
- 英文单词用衬线体（Iowan Old Style / Palatino / Georgia），中文用系统无衬线
- 卡片：1px 细边、20px 圆角、无重阴影；单词与释义之间一条细线
- 底栏：悬浮药丸，毛玻璃，主按钮朱砂红
- 感觉：像一本做得很讲究的单词册，安静、耐看、不复杂
- 适合：每天长时间背词，不抢注意力

### B · 瑞士网格

- 纯白底、黑字、钴蓝 `#1D4ED8` 点缀
- 大号序号 + 2px 黑分隔线，卡片没有圆角和阴影
- 按钮是方形描边，底栏通栏直角
- 感觉：平面设计感强，像一本排版杂志
- 适合：喜欢强对比、利落感；但每天看 10 张卡会略“硬”

### C · 暗色专注

- 炭黑底 `#0F0F0F`，卡片 `#181818`，米白字 `#F4EFE6`，琥珀 `#E0A458`
- 卡片左侧一条 2px 琥珀线，底栏是深色毛玻璃 dock
- 感觉：夜间模式、专注、克制
- 建议：作为 A 的**暗色主题**，不做独立风格

**已定：A 做主风格，C 做暗色模式，B 不用。** A 最贴合“高级但不复杂”，也不容易看腻。

## 3. 页面结构

### 3.1 背单词页

```
┌────────────────────────────────────────────┐
│ ‹  四级大纲 4427 词          第 3 组 / 443 │
│ ────────────────────────────────────────── │
│ ┌─────────────────┐ ┌─────────────────┐    │
│ │ 01    ✓标熟 ☆收藏│ │ 02    ✓标熟 ☆收藏│    │
│ │ abandon         │ │ evaluate        │    │
│ │ /əˈbændən/      │ │ /ɪˈvæljueɪt/    │    │
│ │ ─────────────── │ │ ─────────────── │    │
│ │ v. 放弃；遗弃…   │ │ v. 评估；估价…   │    │
│ └─────────────────┘ └─────────────────┘    │
│ ...（10 张，桌面两列，手机单列）             │
├────────────────────────────────────────────┤
│ 隐藏单词   隐藏释义              [下一组]   │
└────────────────────────────────────────────┘
```

- 桌面 `≥900px` 两列，手机单列。
- 点单词区只隐藏该卡单词（含音标）；点释义区只隐藏该卡释义。
- 底部全局按钮：全部隐藏 / 全部显示；文案随状态切换。
- 「下一组」两段式：第一次点击变「再点一次进入下一组」，3 秒内再点才切组。
- 点「标熟」：卡片绿闪，立即随机换一个新词补位；全书无词可补时显示「本组已全部标熟」。
- 点「收藏」：琥珀星点亮，不换词。
- 左上角返回：弹出退出框。

### 3.1.1 多词性释义

单词有多个词性时，**不合并成一段，也不折叠**，按词性分行展示：

```
v.   放弃；遗弃；离开；终止
n.   放任；狂热
```

规则：

- 左侧固定 34px 词性列（`v.` / `n.` / `adj.` / `adv.` …），右侧释义列左对齐；换行时挂在释义列下，不顶到词性。
- 一行一个词性，行距 5–6px；卡片随行数自然变高，不截断、不省略。
- 单词性也走同一结构，只是只有一行，视觉上不额外加标签。
- 隐藏释义时整块隐藏，占位文案显示「点击显示释义 · 2 个词性」。
- 收藏夹 / 熟词本列表同样多行展示，字号降到 12px，不截断。
- 数据结构：`word.meaning` 用换行分隔（`v. 放弃…\nn. 放任…`），后端 `WordVo` 拆成 `senses: [{pos, meaning}]` 返回，前端不解析字符串。
- 导入模板：Excel「释义」单元格里一行一个词性；PDF 转换脚本负责把 `v. … n. …` 拆行。


### 3.2 退出框

```
        先别走
      要耍起了吗？
   这一组还没背完，确定现在就走？

  [ 我才没有想耍起 ]  [ 不说了先耍起 ]
```

- 「不说了先耍起」= 退出，回主页/来源页。
- 「我才没有想耍起」= 关闭弹框，继续背。
- 点击遮罩也等同「我才没有想耍起」。

### 3.3 主页

- 问候语 + 日期 + **连续 N 天**（保留）
- 当前词书进度卡：环形进度、已学 / 总数、继续背、换词书
- 两个快捷卡：收藏夹（N 词）、熟词本（N 词）
- 没有每日目标，不设“今日新学/复习”数字

### 3.4 我的

- 收藏夹卡：当前 N 词，[背收藏夹] [查看]
- 熟词本卡：当前 N 词，[查看]（**没有背熟词本**）
- 学习提醒开关 + 时间
- 意见反馈
- 退出登录

### 3.5 收藏夹 / 熟词本

- 列表项：单词 + 音标 + 释义首行 + 右侧星标/对勾
- 星标/对勾一键移出，计数全局同步
- 空态不写“暂无数据”，直接引导去背单词
- 收藏夹顶部有「背收藏夹」；熟词本没有

### 3.6 管理后台

Element Plus 常规布局：左侧菜单（词书 / 词条 / 导入 / 用户 / 反馈），右侧表格。不做花哨设计。

## 4. uiverse 组件用法

从 uiverse.io 只取**交互模式**，按上面的 token 重画，避免直接搬 CSS 导致风格不统一：

| 场景 | 参考类型 | 用法 |
|---|---|---|
| 学习提醒 | 细线 toggle switch | 40×22，开启时主色，滑块 18px |
| 标熟 / 收藏 | icon + text button | 16px 线性图标 + 11px 文字，激活只变色，不加发光 |
| 下一组 | pressable button | 按下 `scale(.98)`，两段式时变警示色 |
| 底栏 | glass dock | 毛玻璃 + 1px 边，圆角 999/18 |
| 退出框 | centered dialog | 遮罩模糊 4px，弹入 220ms |
| 单词卡 | border card | 1px 边 + 大圆角，不用重阴影/3D 倾斜 |

**不用**：霓虹渐变、玻璃拟态堆叠、3D 翻转卡片、粒子背景、过度弹跳。高级感来自留白、字体、比例和一致性，不是特效数量。

## 5. 软件名能多长

| 位置 | 限制 / 建议 |
|---|---|
| App Store 名称 | 最多 **30 个字符**（中英文都按字符算）；`神也背单词` 5 字，没问题 |
| App Store 副标题 | 最多 30 个字符 |
| Google Play 标题 | 最多 **30 个字符** |
| iOS 桌面图标名 | 建议 **2–6 个汉字**；`神也背单词` 5 字多数机器能显示，极小屏可能省略 |
| Android 启动器名 | 建议 ≤8 个汉字；`神也背单词` 5 字没问题 |
| Capacitor `appName` | 无硬限制，填 `神也背单词` |
| 页面内 wordmark | 2–4 个汉字最稳；启动页/商店用全称，导航栏可用「神也」 |
| 包名 / App ID | 与显示名无关，`com.shorthand.app` 即可 |

结论：**商店名最多 30 字符；`神也背单词` 5 个字可以直接做图标名和启动主标题。** 如果担心小屏图标被截断，图标下显示「神也」，启动页和商店用全称。`shorthand` 只做项目名/仓库名。
