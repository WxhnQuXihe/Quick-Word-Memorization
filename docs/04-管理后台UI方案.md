# Shortand · 管理后台 UI 方案 v0.1

> 交互原型：`prototype/admin-ui.html`，地址 `http://127.0.0.1:8123/prototype/admin-ui.html?variant=A|B|C`
> 目标：**和用户端完全断开**，做炫酷科技感，但不俗气、不花哨，日常管理要顺手。

---

## 0. 三个方向

### A · Mission Control（推荐）

- 深石墨底 `#08090B`，面板 `#0D1013`，1px 冷灰边 `#1C2228`
- 主强调色：酸性青柠 `#C8F560`；辅助冷青 `#63E6FF`
- 左侧 76px 图标 rail + 顶部系统状态条
- 信息结构：4 个 KPI → 词书运行表 → 系统遥测 + 事件流 → 14 日活跃柱图 + 最近用户
- 感觉：航天控制台 / 数据库运维台；数据密度高，但留白克制
- 推荐理由：最像“真正在运行的系统”，不是把后台做成炫技网页

### B · Blueprint（工程蓝图）

- 浅灰 `#F0F2F0`，纸白面板，信号橙 `#FF4D00`
- 网格背景、横向顶部导航、超大数字、细线表格
- 感觉：实验室 / 工程图纸，明亮、理性、和 A 完全相反
- 适合：白天长时间看表格；但“科技感”偏设计感，不是控制台感

### C · Terminal（终端监控台）

- 纯黑 `#050505`，荧光绿 `#C6FF00`，全等宽字体，轻微扫描线
- 左侧竖排 `SHORTAND ADMIN`，大号 `12,271`，命令提示符光标
- 感觉：服务器终端 / 监控大屏，最硬核
- 风险：看久了累，表单和中文长文本不如 A 舒服；更适合当登录页/系统状态页的彩蛋

**推荐：A 做主后台，C 的终端气质只用在登录页或系统状态页。** B 留作备选，不混用。

## 2. 信息架构

```
/admin/login          登录（终端风彩蛋）
/admin                总览 Dashboard
/admin/wordbooks      词书管理
/admin/words          词条管理（多词性编辑）
/admin/imports        导入记录
/admin/users          用户管理
/admin/feedback       反馈管理
/admin/system         系统状态（可选）
```

登录：单管理员账号，深色全屏，中央 `S` 标识 + 账号/密码 + 一条 `SYSTEM ONLINE` 状态线。

## 3. 页面

### 3.1 总览

- 4 个 KPI：词条总量、注册用户、收藏总数、待处理反馈
- 词书运行表：词书 / 词数 / 学习覆盖率 / 状态 / 最近更新
- 系统遥测：API 延迟、DB 查询、JVM Heap、Uptime
- 事件流：导入、用户、反馈、登录，最近 5 条
- 14 日学习活跃度柱图
- 最近用户：昵称、当前词书、最近学习时间

### 3.2 词书管理

表格：词书 / 词数 / 覆盖率 / 状态 / 更新时间 / 操作（编辑、导入、上架、下架）。
顶部主按钮「新建词书」；右侧可放「导入词条」拖拽区。

### 3.3 词条管理

- 搜索：单词 / 释义 / 词性
- 表格：单词、音标、词性、释义首行、更新时间
- 编辑用右侧 Drawer：单词、音标、**多行释义 textarea（一行一个词性）**、例句
- 多词性预览：`v. 放弃…` / `n. 放任…` 两行，和用户端一致

### 3.4 导入

- 拖拽 `.xlsx / .csv`，最大 12MB
- 队列：文件名、词书、总行数、成功/失败、状态
- 失败行下载 `error.xlsx`
- 导入历史：`import_log`

### 3.5 用户

表格：用户名、昵称、状态、创建时间、最近登录、操作（重置密码、禁用）。
顶部「新建用户」（不开放注册，只有这里能建）。

### 3.6 反馈

列表 + 详情 Drawer；回复后状态变「已回复」。

## 4. 组件清单

| 组件 | 用法 |
|---|---|
| `AdminRail` | 左侧图标导航，active 用青柠底 10% |
| `StatusPill` | `ALL SYSTEMS NOMINAL`，只有状态点有微光 |
| `KpiCard` | 大号 mono 数字 + 小 sparkline |
| `DataTable` | 细线、hover 行、右对齐数字 |
| `ProgressBar` | 4px，青柠填充 |
| `Dropzone` | 虚线边框，拖入高亮 |
| `Drawer` | 右侧编辑词条/反馈 |
| `CommandBar` | 顶部搜索，后续可做 Ctrl+K |
| `TerminalBlock` | 登录页/系统页的终端彩蛋 |

uiverse 参考：细线 toggle、icon button、可按压按钮、毛玻璃 modal；全部按 A 的 token 重画，不直接搬 CSS。
